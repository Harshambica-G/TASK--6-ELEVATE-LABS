# TASK--6-ELEVATE-LABS
 K-Nearest Neighbors (KNN) Classification - Iris Dataset
This project demonstrates a step-by-step implementation of the **K-Nearest Neighbors (KNN)** algorithm using the classic **Iris flower dataset**. It includes data preprocessing, training, evaluation, and visualization of decision boundaries.
 📁 Dataset
The dataset used is the [Iris Dataset](https://archive.ics.uci.edu/ml/datasets/iris), which contains 150 samples from three species of Iris:
- Iris-setosa
- Iris-versicolor
- Iris-virginica
Each sample has 4 features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
🛠 Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
 🧪 What’s Inside
1. Data Preprocessing
- Dropping unnecessary columns (`Id`)
- Feature normalization using `StandardScaler`
2. KNN Classification
- Training `KNeighborsClassifier` with various K values (1 to 10)
- Accuracy evaluation
- Confusion matrix analysis
 3. Visualization
- Plotting accuracy vs. K
- Confusion Matrix
- Decision Boundary using PCA (2D reduction)

 Results
- Best accuracy achieved at **K = 3**, with 100% classification accuracy.
- Decision boundaries show well-separated classes after PCA transformation.
